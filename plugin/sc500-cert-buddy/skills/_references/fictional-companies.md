## Resource naming conventions

- **Servers:** Server1, Server2; SQL1, SQL2; DC1, DC2; DNS1, DNS2 (no space between the noun and the digit).
- **Azure resources:** VM1, VNet1, Subnet1, KV1, RG1, Sub1, Workspace1, Policy1, Group1; storage accounts are lowercase (storage1).
- **Administrators:** Admin1, Admin2.
- **Computers:** Computer1, Computer2.
- **Applications:** App1, App2.
- **Subnets:** Subnet1, Subnet2. **Sites:** Site1, Site2.
- **Offices:** *main office*, *branch office*, *satellite office* (lowercase).
- **People:** never a personal name; use *the user*, or User1, User2, User3 for multiple people.
- **First mention:** define each name the first time it appears (*You have an Azure subscription named Sub1 that contains a virtual network named VNet1.*).
